# WEKINGS — отдельный игровой раздел

Игра доступна по `/games/wekings/`. На странице статистики добавлена только ссылка «Играть». Из существующих файлов изменены только `app.py` (регистрация Blueprint, четыре строки) и `templates/index.html` (одна ссылка). `static/app.js`, `static/style.css`, `scraper.py`, `requirements.txt`, `render.yaml`, модели и маршруты статистики сохранены.

## Запуск на Render

Дополнительные сервисы, Node.js, миграции базы данных и изменения команды запуска не требуются. После публикации этой версии существующий `gunicorn app:app` обслуживает и статистику, и игру. Текущая конфигурация `--workers 1 --threads 4` подходит для игрового хранилища в памяти.

Комнаты хранятся отдельно от базы статистики в памяти процесса, под блокировкой для потоков. Они исчезают при перезапуске/развёртывании; отключившийся участник блокирует очередь до возвращения. В новой вкладке сначала открывается выбор режима и флага; возвращение в онлайн-комнату — отдельной кнопкой. В игре нет общей регистрации или входа через секреты администратора статистики.

Сервер ограничивает число комнат (128) и создание (30 в минуту на процесс). Только игра использует свой лимит тела запроса и проверки Origin. Сервер генерирует броски, проверяет ключ места, очередность, revision и задержку анимации; переданные клиентом результаты кубика игнорируются. Нельзя увеличивать число Gunicorn workers или экземпляров без перехода к общему хранилищу комнат (например Redis). Для масштабирования не нужно менять таблицы статистики.

## Проверка

```
python -m unittest discover -s tests -v
```

Для теста соответствия правил также нужен Node.js **только на машине проверки**, не на Render. `tests/rules_corpus.cjs` создаёт 2 820 ситуаций для сравнения Python и браузерного движка. Регрессионные тесты используют две отдельные SQLite-базы в памяти и закреплённую исходную ревизию Git; не подключаются к production-базе, отключают сканирование и обслуживание.

Девять тестов проверяют правила, параллельные команды, цвета, лимиты, пространство URL, неизменность существующих файлов/маршрутов/API и отсутствие записи игры в БД статистики. В браузере проверены переход «Играть», стартовое меню, комната двух реальных клиентов и серверный ход по `/games/wekings/api/rooms/...`.

## Возврат к прежней версии

До слияния отдельной ветки работающий сайт не меняется. Если после публикации потребуется откат, вернуть предыдущий деплой Render или отменить коммит интеграции. Данные статистики и схема БД не требуют обратных миграций.
