# Wekings Statistics для Render

Сайт собирает реальные данные профилей Wekings, сохраняет их в PostgreSQL и
показывает рейтинг, поиск, фильтры и прирост между снимками.

## Рейтинги организаций

После появления двух завершённых снимков сайт автоматически показывает
рейтинги кланов и братств. Для каждой организации считаются количество игроков,
сумма характеристик и изменение относительно предыдущего снимка. Зелёным
отмечается рост, красным — падение. Нажатие на название раскрывает участников,
а также списки пришедших и ушедших игроков.

## Развёртывание

1. Создайте пустой репозиторий GitHub.
2. Загрузите в него все файлы из этого проекта.
3. В Render выберите **New → Blueprint**.
4. Подключите репозиторий и подтвердите создание сервисов из `render.yaml`.
5. После запуска откройте адрес сайта. Первый полный сбор занимает несколько
   часов, текущий ID проверяемого игрока виден вверху страницы.

## Важные настройки

- Сканирование запускается три раза в сутки по времени Молдовы: в 00:15,
  08:15 и 18:00.
- Вечерний сбор формирует финальный ежедневный отчёт. Если он закончится после
  полуночи, в списке он всё равно останется отчётом за день начала сбора.
- После временной ошибки сбор автоматически продолжится через 5 минут.
- `REQUEST_DELAY=0.3` — пауза между запросами каждого рабочего потока.
- `SCAN_WORKERS=3` — одновременно проверяются три профиля.
- `SAVE_EVERY=20` — прогресс и данные записываются в базу пакетами.
- `MAX_PLAYER_ID` — необязательный ручной предел ID. Обычно определяется
  автоматически по гостевому персонажу.
- `START_SCAN_ON_BOOT=true` — при запуске продолжить прерванный сбор или начать
  самый первый сбор. Завершённый цикл вне расписания повторно не запускается.

Сборщик выполняет один запрос на профиль. Данные раздела «Характеристики»
уже находятся в HTML профиля и становятся видимыми после нажатия в браузере,
поэтому второй запрос не нужен.
