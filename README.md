# Wekings Statistics — version 41

Добавлен раздел админ-панели **⚔️ Арена**.

URL: `/admin/wekings-arena`

Функции:
- сбор событий `type=ARENA` за 1–7 календарных дней;
- сохранение событий в отдельную таблицу `arena_event`;
- группировка по календарному дню и сопернику;
- количество исходящих нападений на каждого соперника;
- общее украденное серебро по каждому сопернику;
- количество входящих атак;
- серебро, потерянное при проигранных входящих атаках;
- итог за выбранный период;
- автоматическое удаление событий арены старше 90 дней вместе с текущей очисткой истории.

Страница ничего не удаляет при обычном просмотре. Сбор создаёт только новые записи, дубликаты не сохраняются.
